### Hi, I'm StaticBeaver 🦫

I'm an independent software developer and builder with a clinical background in healthcare. Spending my daily life inside the healthcare system gives me a direct view of operational bottlenecks, hardware quirks, and inefficient workflows. 

I focus on building pragmatic, lightweight desktop utilities, automation pipelines, and direct hardware communication tools to solve real problems.

---

#### 🔭 What I Work On
- **Direct Hardware & Desktop Tools:** Low-level Win32 USB/Serial communication, thermal printer protocols (TSPL), and responsive Qt/PyQt desktop applications.
- **Workflow Automation:** Removing manual friction from healthcare and clinic operations.
- **Core Stack:** Python, PyQt, Win32 API / ctypes, SQLite, C/C++.

---

#### 🚀 Featured Projects
- **[GapDetect](https://github.com/StaticBeaver/GapDetect):** A lightweight Windows calibration tool for TSPL label printers. Uses raw Win32 USB communication (`GUID_DEVINTERFACE_USBPRINT`) without requiring `libusb` or driver replacements.
