### 🩺 About Me

I am a practicing physician with a deep passion for software engineering, system architecture, and automation. Working directly inside the healthcare ecosystem gives me firsthand experience with the operational friction, hardware bottlenecks, and workflow inefficiencies that clinicians face every single day.

Instead of accepting these pain points, I build practical, high-performance software solutions to solve them.

- 🔭 **Current Focus:** HealthTech desktop applications, automated clinical workflows, and direct hardware communication (thermal printers, barcode scanners, USB RAW I/O).
- ⚙️ **Stack:** Python, PyQt / Qt, Win32 API, ctypes, C/C++, SQLite.
- 🎯 **Philosophy:** No bloated abstractions. Solve real-world edge cases with clean, resilient, and lightweight code.
- 💬 **Ask me about:** Medical informatics, Win32 USB RAW communication, TSPL protocols, and independent desktop app engineering.

### 🚀 Featured Open Source Work

#### 🖨️ [GapDetect](https://github.com/StaticBeaver/GapDetect)
> **One-click calibration & gap measurement for TSPL thermal label printers on Windows.**
> Built with pure Win32 API direct USB communication (`GUID_DEVINTERFACE_USBPRINT`) using `ctypes` — completely bypassing the Windows print spooler with zero third-party driver dependencies (no libusb/Zadig).
